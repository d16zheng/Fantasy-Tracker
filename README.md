# Sports Tracker

React and TypeScript application foundation for following selected sports, teams, games, and live scores.

## Project structure

- `src/components` — shared UI components
- `src/features` — sport, team, and score domain areas
- `src/hooks` — reusable React hooks
- `src/lib` — framework-agnostic utilities
- `src/pages` — route-level views
- `src/services/api` — future online sports data clients
- `src/services/adapters` — future provider-specific data adapters
- `src/styles` — application styles and design tokens
- `src/types` — shared TypeScript types
- `public` — static assets served as-is

## Getting started

Install dependencies with `npm install`, then use `npm run dev` to start the Vite development server.

The source directories intentionally contain placeholders only; application code can be added as the product design is defined.
