## Required Sports Data

### Player

- ID
- Name
- Team
- Position
- Jersey number
- Headshot

### Season Statistics

- Games played
- Points per game
- Assists per game
- Rebounds per game
- Minutes per game

### Game Performance

- Game ID
- Date
- Opponent
- Minutes
- Points
- Assists
- Rebounds

## Main Screens

### Dashboard

Shows an overview of tracked players and recent performance.

### Player Search

Allows users to find professional players.

### Player Details

Displays profile information, season statistics, game logs,
and performance trends.

### Tracked Players

Displays all players currently being followed.

### Player Comparison

Allows statistics for selected players to be compared.

## Data Ownership

### External Provider Data

- Players
- Teams
- Games
- Season statistics
- Game performances

### Application-Owned Data

- Tracked players
- User watchlists
- User preferences
